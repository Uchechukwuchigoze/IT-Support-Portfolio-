# Microsoft Entra ID Administration

## Project Overview

This project demonstrates the administration of identities and access management within Microsoft Entra ID. The objective was to manage users, organize identities using departments and groups, implement authentication methods, understand role assignments, and practice cloud identity management concepts commonly used in modern enterprise environments.

Dynamic Groups:
